# HIMATKN Root Kit — Installation Notes

This ZIP is structured so its contents can be placed at the root of the local HIMATKN repository.

## Before extraction

1. Check `git status --short` in the local repository.
2. Check whether `AGENTS.md`, `progress.md`, `OPEN_CODE_FIRST_PROMPT.md`, `docs/`, or either design-reference folder already exists. Do not overwrite user files blindly; compare/merge first.
3. Extract the design reference folder contents to the repository root. The expected reference paths are `HIMATKN_Public_Design_Reference/` and `HIMATKN_Admin_Panel_Design_Reference/`.
4. Read `AGENTS.md` and `progress.md`, open OpenCode from the repo root, then submit `OPEN_CODE_FIRST_PROMPT.md`.

This kit does not modify the GitHub repository or production deployment. It contains the static design references and local work instructions only.
