# HIMATKN — Public Figma Reference Pack

This pack is the local visual reference for the **public website only**. It is intended to reduce repeated Figma/context reads during OpenCode sessions.

## Contents

- `screenshots/public-desktop.png` — main desktop public homepage artboard.
- `screenshots/public-mobile.png` — main mobile public homepage artboard.
- `states/programs-empty-state-desktop.png` and `states/programs-empty-state-mobile.png` — alternate program empty states.
- `states/publications-empty-state-desktop.png` and `states/publications-empty-state-mobile.png` — alternate publication empty states.
- `FIGMA_DESIGN_SPEC.md` — concise visual and implementation specification.
- `OPEN_CODE_ALIGNMENT_PROMPT.md` — prompt for the Batch 1.1 visual alignment pass.

## Installation in the repository

Extract the `HIMATKN_Public_Figma_Reference` directory into the repository root, then have OpenCode read `README.md` and `FIGMA_DESIGN_SPEC.md` before the alignment pass. Do not overwrite any existing project files.
